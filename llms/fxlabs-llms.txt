# APIsec (Fxlabs)

> APIsec is an AI-powered API and application security platform delivering continuous, automated security testing with AI-driven exploit validation, threat modeling, and attack-surface mapping across the OWASP API Security Top 10. Listed as "Fxlabs" in Canaan Partners' portfolio (seed), the company resolves to apisec.ai. Added to the API Evangelist network for enrichment.

## Product
- [APIsec Platform](https://apisec.ai/platform): Continuous API security scanning and OWASP API Top 10 coverage
- [apisec Surface (OSS)](https://apisec.ai/surface): Open-source mapping of APIs, endpoints, and AI connections
